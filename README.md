# Brightside Studio (demo site)

A small sample marketing site used to demo and review the ronda plugin for ChatGPT.
It is intentionally simple: a home page with a hero and features, a pricing page,
and a header with a mobile menu.

Known issue (left in on purpose for the demo): on mobile, the menu does not close
after you tap a link.

```bash
npm install
npm run dev   # http://localhost:3000
npm run build
```
